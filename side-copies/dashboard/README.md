# Rebella Moderation

Passcode-locked dashboard where Bonnie approves or rejects real content for Rebella. Same pink look as before.

- `index.html`: passcode gate + dashboard (noindex,nofollow), plus `robots.txt` (Disallow: /)
- `js/config.js`: salted passcode hash ONLY (PBKDF2-HMAC-SHA256, 250k iterations). Generated by `build_gate.py`.
- `queue.enc.json`: the real candidate queue, **AES-GCM-256 encrypted** with a key from PBKDF2(passcode, its own salt, 250k).
  Written by the box pipeline (`/workspace/rebella-pipeline/pipeline.py scan|queue`). Contains the items, the box's
  decisions, and the secret relay topic. Nothing readable without the passcode.
- `js/crypto.js`: Web Crypto helpers (same format as the box). `js/app.js`: gate, decrypt queue after unlock,
  approve/reject, live status, export. `js/items.js`: empty stub (kept so old links don't 404).

## How a decision travels
1. Bonnie taps Approve or Reject. It's saved in this browser and sent, encrypted, to a secret ntfy.sh topic.
2. The box relay (`pipeline.py relay-ensure`) decrypts it. Only messages made with the passcode key are accepted.
3. Approve: the box builds the article page, commits, pushes, then checks the page is live. Reject: logged, never suggested again.
4. The box sends encrypted status pings back. The card shows "Approved, publishing…" then "Live ✓" with a link
   (the page also checks the article URL itself).

## Set the passcode (same passcode as the Rebella site)
    REBELLA_SITE_PASSCODE='...' python3 build_gate.py && python3 /workspace/rebella-pipeline/pipeline.py queue
Never commit the plaintext. After a passcode change, rebuild the queue (second command) and restart the relay.

## Limits
Client-side gate on a static host: it hides the UI, but the gate hash and the encrypted queue are public, so a weak
passcode could be guessed offline. Use a long one. ntfy.sh is a free public relay (rate limits, ~12 h message cache).

## Bonnie's Dashboard extras (local branch `moderation-weather-chip`, not live)
- `js/hud.js` + `css/hud.css`: header weather chip (Open-Meteo, fixed Perth coordinates, no location prompt, cached 30 min,
  `?weather=sun|hot|cloud|fog|rain|storm|night`), emoji story, age-linked fact ticker (simmie-chat `facts.json` + `age-dial.json`,
  `?age=`), footer status lights (QUEUE / FRESH / LINK / SKY, real data only), gauge, waveform, background space loop (`media/`) + faint code drift.
- `js/talk.js`: the `simmie - tty` terminal. Idle scripts, SYSTEM REPORT (real counts + `pipeline-stats.json`), facts; tap to talk to Simmie
  over the chat page's own encrypted relay (`js/simmie-crypto.js` is an exact copy). Only the derived chat key is kept, in sessionStorage.
  Ask Dad: the one pop-up, same relay, plain message tagged `type:"ask-dad"`.
- `js/mlog.js`: mission log of real page events (never message text). `js/interludes.js`: animal (9 s) and space (12 s) interludes.
- `pipeline-stats.json`: aggregate-only counts from `/workspace/rebella-pipeline/export_stats.py` (sample; omitted when older than 6 h).
All of it starts only after the passcode gate, is static under reduced motion and pauses while the tab is hidden.
